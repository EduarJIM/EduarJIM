  <h2>👨‍💻 Sobre Mí</h2>
</div>

<p align="center">
  👋 ¡Hola! Soy <strong>Eduar Jiménez López</strong>, Tecnólogo en <strong>Análisis y Desarrollo de Software (ADSO)</strong> y <strong>Full Stack Developer</strong>.<br>
  Me apasiona concebir, estructurar y construir aplicaciones completas y escalables, combinando interfaces de usuario modernas y dinámicas con arquitecturas backend sólidas, seguras y de alto rendimiento.
</p>

<p align="center">
  🎯 <strong>Enfoque técnico:</strong> Desarrollo guiado por especificaciones (<em>Specification-Driven Development</em>), <strong>Domain-Driven Design (DDD)</strong>, arquitecturas basadas en componentes, diseño de APIs RESTful limpias y buenas prácticas de código estructurado.<br>
  🚀 <strong>Objetivo:</strong> Crear software funcional y de alto impacto que resuelva problemas reales del sector productivo.
</p>
