  <h2>👨‍💻 Sobre Mí</h2>
</div>

<p align="center">
  👋 ¡Hola! Soy <strong>Eduar Jiménez López</strong>, Tecnólogo en <strong>Análisis y Desarrollo de Software (ADSO)</strong> y <strong>Full Stack Developer</strong>.<br>
  Me especializo en diseñar y programar soluciones web y de escritorio que resuelven problemas reales de negocios, combinando interfaces de usuario dinámicas con arquitecturas backend seguras, eficientes y desacopladas.
</p>

<p align="center">
  🎯 <strong>Principios de Ingeniería:</strong> Enfoque riguroso en <strong>Domain-Driven Design (DDD)</strong>, desarrollo guiado por especificaciones (<em>Specification-Driven Development</em>), principios SOLID, arquitecturas modulares en portales y código testeable con cobertura de pruebas unitarias.<br>
  🚀 <strong>Objetivo Profesional:</strong> Aportar valor en equipos de desarrollo ágiles mediante software escalable, modular y orientado a la excelencia técnica.
</p>
